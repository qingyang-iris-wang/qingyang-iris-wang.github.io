# qingyang-iris-wang.github.io

A minimal, single-page personal website, published by GitHub Pages from the root of `main`.

## Personalize

- Edit the introduction in `index.html`.
- Add a photo at `assets/photo.jpg`, then replace the initials with the image markup shown in the HTML comment.
- Replace the CV placeholder with a link to the CV's Google Docs sharing URL, using the example in `index.html`. In Google Docs, use **Share → Anyone with the link → Viewer**.

Open this repository in GitHub Desktop, review your changes, commit, then choose **Push origin**. GitHub Pages publishes updates automatically.

## Search visibility

Both HTML pages include `noindex` directives for search engines that support them. Do not add a robots.txt rule blocking these pages: crawlers need to read the directives. This is search exclusion, not access control. The website and this repository remain public; linked documents have their own sharing and indexing settings.

## Template

Simplified from [Minimal Light by Yaoyao Liu](https://github.com/yaoyao-liu/minimal-light), released under CC0 1.0. The template license is preserved in `TEMPLATE-LICENSE.txt`. The starter uses system fonts and has no analytics, third-party scripts, or build dependencies.
